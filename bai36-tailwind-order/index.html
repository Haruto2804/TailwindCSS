🔢 Minh họa `order-*` trong Tailwind CSS

Các item được định nghĩa trong HTML theo thứ tự A-B-C-D-E. Lớp `order-*` thay đổi thứ tự hiển thị.

Thứ tự HTML: A,B,C,D
A (Last)
B (None)
C (First)
D (Order 1)
E (order-2)

Thứ tự hiển thị (từ trái sang phải): C, B, D, A,E

  • `order-first`: Đặt item ở vị trí hiển thị đầu tiên (giá trị CSS là `-9999`).
  • `order-none`: Đặt item ở vị trí mặc định (giá trị CSS là `0`).
  • `order-1`: Đặt item ở vị trí có giá trị dương, nằm sau `order-none` và trước `order-last`.
  • `order-last`: Đặt item ở vị trí hiển thị cuối cùng (giá trị CSS là `9999`).
  • `order-(number)`: Số càng nhỏ thì độ ưu tiên càng cao

💡 Quy tắc sắp xếp

Thứ tự các item được xác định bởi giá trị số của `order`:

order-first (rất âm) < order-none (0) < order-1 < order-2 < ... < order-last (rất dương)
